# scoop-cascade

[Scoop](https://scoop.sh) bucket for [cascade](https://github.com/Mearman/cascade) on Windows.

## Install

```powershell
scoop bucket add cascade https://github.com/Mearman/scoop-cascade
scoop install cascade
```

## Manifest

`bucket/cascade.json` is auto-generated by the cascade CI release pipeline on every tagged release. Manual edits will be overwritten.
